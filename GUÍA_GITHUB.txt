📝 PASOS PARA CREAR EL REPOSITORIO EN GITHUB
────────────────────────────────────────────────────────────────────────────────

PASO 1: Crear cuenta GitHub (si no tienes)
─────────────────────────────────────────
1. Ve a https://github.com
2. Clic en "Sign up"
3. Completa email, contraseña, usuario
4. Verifica email


PASO 2: Crear nuevo repositorio
──────────────────────────────────
1. Clic en ➕ (arriba derecha)
2. Selecciona "New repository"
3. Rellena:
   
   Repository name: crowd-counter-ai
   Description:     Intelligent People Counting System with YOLOv8 and Flask
   Visibility:      Public ✓ (para que otros lo vean)
   
4. ✓ Add a README file
5. ✓ Add .gitignore (selecciona "Python")
6. ✓ Choose a license (MIT o Apache 2.0)
7. Clic en "Create repository"


PASO 3: Clonar el repositorio en tu PC
───────────────────────────────────────
Abre PowerShell en Windows:

cd c:\Users\mmmmm\Documents
git clone https://github.com/tu-usuario/crowd-counter-ai.git

(Cambia "tu-usuario" por tu usuario de GitHub)


PASO 4: Copiar archivos del proyecto
──────────────────────────────────────
Copia estos archivos al repositorio clonado:

├── app.py
├── contador_motor.py
├── yolov8n.pt
├── README.md (ya creado ✓)
├── ANÁLISIS_TÉCNICO.txt
├── templates/
│   └── interfaz.html
├── static/
│   └── videos/ (crear carpeta vacía)
│
├── .gitignore (crear - ver más abajo)
├── requirements.txt (crear - ver más abajo)
└── LICENSE (crear si no existe)

PASO 6: Configurar Git en tu PC (primera vez)
───────────────────────────────────────────────
En PowerShell:

git config --global user.name "Tu Nombre"
git config --global user.email "tu-email@ejemplo.com"


PASO 7: Subir archivos a GitHub
────────────────────────────────
En PowerShell (en la carpeta del repo):

cd c:\Users\mmmmm\Documents\crowd-counter-ai

# Ver qué cambios hay
git status

# Añadir todos los archivos
git add .

# Crear commit ("mensaje descriptivo")
git commit -m "Initial commit: Crowd Counter AI project with Flask and YOLOv8"

# Subir a GitHub
git push origin main

✅ ¡Listo! Tu proyecto estará en GitHub


PASO 8: Protecciones y mejoras (opcional)
──────────────────────────────────────────

En la página del repo en GitHub:

1. Settings → Branches
   → Add rule
   → Branch name pattern: main
   → Require pull request reviews
   → Require status checks

2. Add Topics (etiquetas)

   - yolov8

3. Enable "Discussions" (para comunidad)

❓ PREGUNTAS FRECUENTES
────────────────────────────────────────────────────────────────────────────────

P: ¿Debo subir el archivo yolov8n.pt?
R: NO. Es muy grande (6.2MB). Se descarga automáticamente. Agrégalo a .gitignore

P: ¿Debo subir videos de ejemplo?
R: NO. Pueden ser enormes. Agrégalos a .gitignore y explica cómo obtenerlos

P: ¿Cómo protejo mi código?
R: Usa licencia MIT/Apache y especifica términos de uso en README

P: ¿Puedo hacer dinero con esto?
R: Sí, pero respeta las licencias de YOLOv8 (AGPL o comercial)

P: ¿Cómo atraigo contribuidores?
R: Código limpio, documentación, issues claros, buenos commits
